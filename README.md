# Sazare

Free, open source hooks and smart contracts built the way Sazare thinks things should work.

## What this is

This repo holds opinionated versions of hooks and other smart contracts. Each one reflects a deliberate view on how something should behave on-chain. They are not neutral, all-purpose building blocks.

- **Free to use.** No fees, no gatekeeping, no permission needed.
- **Open source.** Read it, fork it, deploy it, build on it.
- **Opinionated.** Each contract makes clear choices instead of trying to cover every case. If you disagree with a choice, fork it and change it.

## Status

Early. Contracts are being added. Nothing here is audited yet, so use it at your own risk.

## Development

Built with [Foundry](https://book.getfoundry.sh/).

```shell
forge build
forge test
forge fmt
```

## Contributing

Issues and pull requests are welcome. If you're proposing a change to how a contract behaves, explain why. The opinions are the point.
